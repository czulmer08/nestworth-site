The one-minute proof it works

Open your site in a private / incognito window and sign in with a different Google account than your own. If you get through the permission screen and land in the app, sharing will work for others too. If you're blocked or stuck, the items below are why.

1

Who can sign in (consent)

Google Cloud Console ▸ Google Auth Platform (the left-sidebar pages: Audience, Branding, Data Access)

Heads-up: with an unverified app, people will see a one-time "Google hasn't verified this app" screen and tap Advanced ▸ Continue. That's normal and safe — the Read me now explains it. Full Google verification removes that screen but isn't required to share.

2

Sign-in client (OAuth Client ID)

Google Auth Platform ▸ Clients ▸ your Web application client

3

Picker key (the one GitHub flagged)

APIs & Services ▸ Credentials ▸ the browser API key "NestWorth Picker"

4

Enabled APIs

APIs & Services ▸ Enabled APIs & services

Not part of this setup: receipt scanning uses a separate free key that each person adds themselves inside the app (from aistudio.google.com/app/apikey). It's on-device only and never touches this project — so nothing here affects it.
