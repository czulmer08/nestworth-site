# NestWorth

A private, phone-first budgeting app that lives in **your own** Google Drive. NestWorth is a single
self-contained HTML file that runs entirely in the browser and talks directly to the Google Sheets API —
there is no NestWorth server or database. It plans around real paydays, treats goal money as savings
(not spending), and keeps budget, cash flow, goals and net worth on **one** financial model. "Wren," a
scripted (non-LLM) narrator, explains the numbers the app already computed.

### Binary assets the pages reference (keep these in the repo)
`app.html`, `index.html` and `about.html` reference these files by name — make sure they exist at the repo
root (they are **not** regenerated by the build and are not included in a source-only export):

- `apple-touch-icon.png` (home-screen icon; also precached by `sw.js`)
- `icon-512.png` (logo fallback)
- `NestWorth Logo.png` (landing hero logo)
- `manifest.webmanifest` (PWA manifest, referenced by `index.html`)

If you replace any Wren image, bump the `CACHE` version string in `sw.js` so clients pick up the new art.

## Tests

Automated suites live in `verify-*.js` (plus `golden-suite.js`). Each is self-contained: Node + Playwright,
loads `app.html`, asserts, exits non-zero on failure.

```bash
npm i -D playwright && npx playwright install chromium   # one-time
node verify-golden-invariants.js        # run any single suite
node verify-mutation.js                 # MUST be run alone (it rewrites app.html and restores it)
```

`verify-mutation.js` is a validity-gated "test of the tests." Do not run it in a parallel batch.
`fixtures/meta/` holds the historical metadata documents that `verify-migration.js` migrates and checks.

Current executed results, with the build hash under test, are in **`TEST_RESULTS.md`**.

## Not in this repo (by design)

Never commit real household financial data (`*.xlsx` ledgers) to a public repository.
